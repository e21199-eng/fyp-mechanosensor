Project Overview

Ego-Motion Cancellation in Vibration-Based Mechanosensors

In this project, a vibration-based artificial robotic antenna (feeler) — inspired by insect antennae — is constructed using an accelerometer mounted on the tip of a plastic tube. This antenna is used for detecting contacts with surrounding objects.

The antenna is mounted on a Pan-Tilt unit, which is then attached to a mobile robot platform. The key challenge with this type of mechanosensor is self-sensing due to ego-motion — vibrations caused by the robot's own movement interfere with contact detection. This project aims to cancel the effects of ego-motion using a bio-inspired algorithm.

Harischandra & Dürr (2012) — IEEE ROSE

"A Forward Model for an Active Tactile Sensor Using Echo State Networks"

  • Objective: Predict expected sensor reading of robotic antenna to cancel ego-motion
  • Method: Echo State Network (ESN) — a recurrent neural network for chaotic time series
  • Setup: Accelerometer on antenna tip + accelerometer on robot platform + servo position
  • Key result: Successfully detected 34 true touch events from 35 disturbances with 100% accuracy
  • Relevance: This is the core bio-inspired algorithm our project builds upon
Open PDF

Harischandra & Dürr (2013) — BICS Conference

"Prediction of Self-induced Mechanoreceptive Sensor Readings in an Insect-inspired Active Tactile Sensing System"

  • Objective: Extend the 2012 system to two antennae with 3D movement patterns
  • Method: Single ESN predicting both left and right antenna sensor readings simultaneously
  • Scenarios tested: Straight path, curved path, and spiked wheels (simulating walking robot)
  • Key result: 96% success rate distinguishing 53 true touch events from 252 disturbances
  • Relevance: Confirms ESN forward model works across complex movement scenarios
Open PDF

Gunasekara, Kaldera, Harischandra & Samaranayake (2019) — Instrumentation Journal

"Distance Estimation and Material Classification of a Compliant Tactile Sensor Using Vibration Modes and SVM"

  • Objective: Improve contact distance estimation and material classification using the same antenna sensor
  • Method: FFT-based dominant frequency analysis + SVM classifier (vs ANN benchmark)
  • Key finding: Vibration mode changes at 80% of antenna length — causes non-linear distance readings near tip
  • Hardware: MPU6050 accelerometer on acrylic tube + Raspberry Pi 3 + Pan-Tilt unit
  • Key result: SVM achieved 99.2% accuracy vs 80.8% for ANN at lower computational cost
  • Relevance: Direct predecessor project — same hardware platform and supervisors

Hoinville, Harischandra, Krause & Dürr (2014) — Living Machines (LNAI 8608)

"Insect-Inspired Tactile Contour Sampling Using Vibration-Based Robotic Antennae"

  • Objective: Physically implement the Contour-net model on a real robot using vibration-based antennae
  • Method: CPG-based control with Hopf oscillators; each contact triggers a 180° phase shift causing antenna to "bounce off" surfaces
  • Platform: Two vibration-based antennae mounted on a robotic platform — same type as our project's setup
  • Key result: Successfully traced 3D object contours and localized contact events in 3D space
  • Bio-inspiration: Mimics stick insect (Carausius morosus) antennal searching behavior switching from broad search to local sampling on contact
  • Relevance: Demonstrates the physical platform closest to our project — Pan-Tilt with vibration-based antenna and accelerometer
Open PDF

Harischandra, Krause & Dürr (2015) — Frontiers in Computational Neuroscience

"Stable phase-shift despite quasi-rhythmic movements: a CPG-driven dynamic model of active tactile exploration in an insect"

  • Objective: Model the Central Pattern Generator (CPG) driving rhythmic antennal movements of stick insects
  • Method: Two-level CPG — Hopf oscillators for rhythm generation + Pattern Formation Network for joint kinematics (16 Fourier components)
  • Key finding: SP joint must lead HS joint by exactly 10–30° to produce natural elliptical antenna tip trajectory — outside this range, the pattern collapses
  • Proprioceptor ablation: Removing hair field sensors only changes joint amplitude and offset — the phase coupling remains stable (coded into CPG)
  • Platform: 3D skeletal simulation of stick insect head-antennal system using Python + ODE physics engine
  • Relevance: The CPG framework directly informs how our Pan-Tilt unit should move the antenna — bio-inspired oscillatory movement pattern for efficient contact detection
Open PDF
